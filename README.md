# HELLOIAM · витрина ноябрьского запуска

Снимок от 11 ноября 2026 года. В архиве код витрины, шрифты, метаданные каталога и исходники постов и игр.

## Запуск

Распакуйте ZIP. Положите свои изображения, видео и превью по относительным путям из `MEDIA-FILES.txt`. Затем из каталога с этим README запустите сервер Python 3.

```sh
python3 -m http.server 8774 --bind 127.0.0.1 --directory '10 - launch 2026-11'
```

Откройте [витрину](http://127.0.0.1:8774/showcase/). Если порт занят, замените 8774 на свободный в команде и в адресе. Витрина использует HTTP для загрузки локального каталога. Для просмотра достаточно Python 3 и браузера.

## Где вносить изменения

- `10 - launch 2026-11/showcase/` — главная и страницы витрины, общие стили в `styles.css`, навигация в `showcase.js`.
- `objects.html`, `emoji.html`, `media.html` внутри `showcase/` — список объектов, эмодзи и каталог медиа. `object-forms.js` управляет открытием форм и выбором объекта.
- `showcase/media.js`, `showcase/media-catalog.json` и `01-objects/02-media-unsorted/` — каталог, метаданные и оригиналы медиа. Названия, отредактированные в браузере, можно перенести через «Экспорт названий» и «Импорт названий».
- `04-promo-media/` — галерея «Посты с медиа», которая открывается из «Постов об объектах». Другие посты, трейлеры и игры разложены по соседним папкам.
- `docs/DESIGN.md` — структура и дизайн витрины. Брендбук и локальные шрифты лежат в `02-claude-session 2026-11-10/design-system/` внутри папки запуска.

Чтобы обновить каталог после изменения папки медиа, установите FFmpeg и выполните из корня архива:

```sh
python3 scripts/build-showcase-media.py
```

## Состояние форм

«Добавить объект» сразу открывает макет создания эмодзи. «Добавить медиа» показывает поля описания и референса после выбора объекта. Переход с карточки эмодзи сразу подставляет объект. Это интерактивные макеты. Подключение промптов, генерации и сохранения результата — отдельный этап разработки.
