# KHASH · два трейлера

Промо helloiam.am в ноябрьской дизайн-системе v1. Две версии на общей монтажной сетке, каждая по 25 секунд в 4:5. Палитра — чёрный #0f0f10, красный #c5342e, белый #ffffff и жёлтый #f6c757. Шрифт — Instrument Sans Bold. Крупные титры читаются в мобильном превью. Англоязычные реплики и медиа взяты из [согласованного плана](../../docs/plans/2026-11-10-khash-trailers.md).

| Время | It Simmered All Night | Breakfast Got Out of Hand |
|---|---|---|
| 0–4 с | Красная R проступает из чёрного под низкий удар. | R влетает как штамп, календарь появляется на щелчке. |
| 4–7 с | Туман, приглушённая палитра, гул. | Тот же туман в тёплой гамме, короткая мелодия. |
| 7–11 с | HA → HAHAHA → HASHHHH. Смех переходит в шипение, затем тишина. | Тот же набор букв распирает кадр. На SHHHH музыка и смех останавливаются. |
| 11–15 с | Сложенный лаваш приближается, в паузе слышен треск. | Тот же лаваш под подчёркнутый хруст, мелодия возвращается. |
| 15–19 с | Приближение к тосту останавливается на титре про 8 AM. | Тот же тост, звон бокалов на музыкальной доле. |
| 19–25 с | HASHHHH сжимается в KHASH на чёрном. Затем зимний слоган. | Лишние буквы разлетаются, K встаёт перед HASH. Фирменный жёлтый #f6c757 с чёрными титрами. Этот кадр используется как обложка. |

Видео тумана начинается с 1,5 с исходника и кадрируется по центру. Лаваш и тост — фотографии с движением кадра. Они показывают контекст застолья. Синтезированные музыка и эффекты сведены отдельно для каждого жанра.

`index.html` открывает готовые MP4 с нативным управлением. `scene.html?genre=horror&t=8` показывает выбранный момент композиции, `genre=comedy` переключает жанр. В браузерном превью ролики запускаются по нажатию. Исходники монтажа — `scene.html`, `scene.css`, `scene.js`, `sound.py` и `render.cjs`.

Для повторного экспорта нужны Node.js, Playwright с Chromium, Python 3 и FFmpeg. Команда из этой папки — `node render.cjs`. Можно передать `horror` или `comedy` для одного ролика. Если Playwright установлен вне проекта, путь к модулю передаётся в `KHASH_PLAYWRIGHT`.
